# 数字合成大挑战

基于 Cocos Creator 3.8.8 的竖屏数字合并小游戏原型。

## 当前功能

- 开始界面与玩法说明
- 5x5 数字棋盘
- 点击选择相邻同数字方块进行合并
- 分数与本地最高分
- 无可用合并时判定失败
- 重新开始
- 激励视频模拟接口与一次复活
- 本地基础分析事件：开局、合并、结束、广告开始/奖励

## 本地开发

用 Cocos Creator 3.8.8 打开本目录的 `package.json` 所在文件夹，打开 `assets/scenes/main.scene`，点击预览。

## 构建

项目已经生成 Web 移动版静态产物到 `docs/`，可直接部署到 GitHub Pages、对象存储或任意静态站点。

## 目录

- `assets/scenes/main.scene`：主场景
- `assets/scripts/GameRoot.ts`：游戏逻辑和 UI 构建
- `docs/`：可直接部署的 Web 构建产物

## 抖音小游戏后续接入

当前版本保留了广告模拟入口和本地分析事件。正式上线抖音小游戏前需要：

1. 在抖音开发者后台创建小游戏并取得 AppID。
2. 在 Cocos Creator 中安装/启用抖音小游戏构建插件。
3. 把 `tryRevive()` 中的模拟广告替换为抖音激励视频广告 API。
4. 根据后台合规要求补充隐私政策、用户协议、实名/防沉迷等平台能力。
5. 将本地分析事件替换或同步到实际的数据接收端。
